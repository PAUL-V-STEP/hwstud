# hwstud.ru — локальная версия

Реализуется по финальным требованиям 2.1. Текущий объём — **этап 7: файлы установки и DEPLOY**. Все семь этапов реализации завершены; производственная установка не выполнялась.

Уже доступны: SQLite и миграции, вход студента по нику, вход преподавателя, четыре группы, сессии и CSRF, BPMN-интерфейс с двумя темами, очередь `jobs`, SMTP-задачи, клиент ProxyAPI и базовый монитор баланса.

Для лекций работают: загрузка PPTX + PDF до 40 МБ, проверки и предупреждения, рендер WebP, предпросмотр, сохранение и обновление по названию, восстановление прерванного сохранения, ручное открытие по группам, анонсы, «Слайд + текст», «Конспект», защищённые изображения и режим экзамена. GPT-задачи разбора сокращений созданы, но реальные запросы блокируются до подтверждения моделей.

Дополнительно работают: экран подтверждения терминов и источников, конфликты расшифровок, общий глоссарий, подсветка сокращений, литература с фильтрами и цитированиями, ручное редактирование, PowerPoint/TXT-блок и выгрузки XLSX, Markdown, DOCX и PDF. `source_meta` использует GPT только после подтверждения моделей; сервер внешние ссылки не открывает.

Для домашних работ реализованы: матрица заданий, загрузка PDF/JPG/PNG/TXT/DOCX до 10 МБ, DOCX с текстом и до пяти скриншотами в порядке документа, четыре попытки, статусы, GPT-проверка через очередь, одобрение преподавателем, повторный платный запрос по явной кнопке, запросы на разбор, результаты и CSV. Полный монитор ProxyAPI включает настройки цен и порогов, расход, прогноз, письма, историю и пробное снятие паузы.

Для связи реализованы: объявления по группам и расписанию, закрепление, непрочитанные и отметки прочтения, ссылки с учётом доступа, ветки вопросов, ответы преподавателя, закрытие и повторное открытие, лимит 10 сообщений в сутки, письма преподавателю и почасовая сводка после 30 писем или постоянно. SMTP работает через очередь с повторами.

Добавлены: настройка экзамена по группам и времени, личный SWOT, кривая распределения с отметкой «вы здесь», полная студенческая и преподавательская справка, управление группами и никами, блокировка и удаление ника с подтверждением, освобождение места и повторное использование ника, редактор «О курсе», ежедневные и еженедельные копии, проверка и восстановление архива, временный архив работ, двойное подтверждение удаления студенческих данных и продолжение после сбоя.

На REG.RU приложение не разворачивается этим пакетом автоматически.

## Запуск на Windows

Нужен Python 3.12. В проекте используются только инструменты из `docs/03-ARCHITECTURE.md`.

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m app.tools.init_local
.venv\Scripts\uvicorn.exe app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

Открыть: <http://127.0.0.1:8000>.

`init_local` создаёт `.env`, генерирует локальный секрет сессии без вывода в терминал и применяет миграции. Существующий `.env` не перезаписывается.

## Вход преподавателя

1. Откройте `/admin/login`.
2. При первом входе, если собственный пароль ещё не задан, используйте пароль **`admin`**.
3. Сайт сразу откроет «Настройки → Смена пароля». Остальная админка до смены закрыта.
4. Введите текущий `admin` и дважды новый пароль длиной не менее 12 символов. Нельзя оставить `admin`.
5. После смены следующий вход выполняется только с новым паролем.

Новый пароль хранится в SQLite как scrypt-хеш. Начальный и новый пароли не записываются в журнал. Сменить пароль позднее можно в том же пункте настроек с проверкой текущего пароля.

При желании задать собственный пароль заранее по-прежнему можно через `python -m app.tools.hash_password` и `ADMIN_PASSWORD_HASH` в `.env`.

Пароль и другие секреты не передавать в чат и не помещать в код.

## Проверка тестов

```powershell
.venv\Scripts\python.exe -m pytest
```

Тесты не обращаются к ProxyAPI или SMTP: внешние сервисы заменены заглушками.

## Проверка моделей — только после подтверждения

После заполнения `PROXYAPI_KEY` преподаватель отдельно сверяет модели и цены с каталогом ProxyAPI. Команда ниже выполняет реальные запросы, которые **могут быть платными**:

```powershell
.venv\Scripts\python.exe -m app.tools.check_models --confirm-paid
```

Без `--confirm-paid` сетевых запросов нет. Результаты реальной проверки добавляются в `TESTING.md`.
