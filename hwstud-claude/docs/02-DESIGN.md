# Концепция дизайна сайта hwstud.ru

Финальная версия 2.1 от 23.11.2026. Описание внешнего вида, навигации и поведения интерфейса. Функции — в 01-FUNCTIONS.md (финальная версия 2.1).

## 1. Идея: «Курс как процесс»

Сайт оформлен как рабочая тетрадь аналитика, в которой сам курс нарисован бизнес-процессом. Каждый раздел имеет форму инструмента, который изучается в лекциях: BPMN (Business Process Model and Notation — нотация моделирования бизнес-процессов), диаграмма Ганта, матрица Эйзенхауэра, SWOT, распределение вероятности. Символы ИИ — узлы и связи нейросети — появляются только там, где действительно работает ИИ.

| Раздел сайта | Форма в дизайне | Смысл |
|---|---|---|
| Навигация | BPMN-схема: событие → задачи → шлюз → результат | Студент «идёт по процессу» курса |
| Объявления | Сигнальное событие BPMN (треугольник в круге) | Сигнал — сообщение для всех участников |
| Лекции | Диаграмма Ганта | План курса по плановым датам; открывает лекции преподаватель |
| Глоссарий, литература | Хранилища данных BPMN (цилиндры) | Справочные данные, к которым обращаются задачи |
| Задания | Матрица Эйзенхауэра | Что сделать сейчас, что запланировать, что ждёт проверки, что готово |
| Проверка | Шлюз-ромб с нейросетевым узлом внутри | Решение по работе проходит через ИИ и человека |
| Результаты | Кривая распределения баллов с отметкой «вы здесь» | Своё место в группе без чужих имён |
| Личный кабинет | Личный SWOT | Сильные и слабые стороны, возможности и угрозы по своим данным |
| Связь с преподавателем | Две дорожки BPMN и поток сообщений с конвертом | Переписка как обмен сообщениями между участниками |
| Режим экзамена | Событие-таймер (часы в круге) и штриховка | Лекции, глоссарий и литература закрыты на время экзамена |

Главный принцип: форма раздела объясняет его работу. Студент, который прошёл курс, узнаёт в интерфейсе инструменты из лекций.

## 2. Визуальный язык

### 2.1. Две темы: «Тетрадь» и «Синька»

- **«Тетрадь» (светлая).** Фон — бумага с тонкой миллиметровой сеткой: шаг 8 px, каждая пятая линия чуть темнее. Схемы — графитом и чертёжным синим, линии 0,5–1,5 px.
- **«Синька» (тёмная, blueprint).** Тёмно-синий фон, сетка и линии светлые, как на инженерной кальке.
- Переключатель темы в шапке. По умолчанию тема берётся из настроек системы, выбор запоминается в браузере.
- Сетка видна только на фоне страницы. Под текстом лекций и в карточках фон сплошной, чтобы сетка не мешала чтению.

Правило цвета: бирюза — только для ИИ, оранжевый — только для сроков и объявлений. Так цвет сразу говорит, кто действует: ИИ, преподаватель или сам студент.

**Контраст.** Яркие цвета «графики» — для значков, контуров, полос, заливок и линий схем. Текст статусов и подписей в светлой теме — только более тёмными цветами «текст». Их контраст на фоне #F6F4EE и #FFFFFF — от 4,9:1 до 6,3:1, это не ниже 4,5:1 по WCAG 2.1 AA. В тёмной теме яркие цвета подходят и для текста: контраст на #15253D — от 6:1.

### 2.3. Шрифты

- **IBM Plex Sans** — основной текст и интерфейс.
- **IBM Plex Mono** — заголовки разделов, номера слайдов и операций, даты, баллы, счётчики.
- Оба шрифта с кириллицей, лицензия OFL (Open Font License), файлы хранятся на сервере.

| Элемент | Размер, px | Начертание |
|---|---|---|
| Заголовок страницы | 32 | Mono, 600 |
| Заголовок блока | 22 | Mono, 500 |
| Текст к слайду | 18 | Sans, 400, межстрочный 1,6 |
| Основной текст | 16 | Sans, 400 |
| Подписи, статусы, счётчики | 14 | Sans или Mono, 500 |

Текст мельче 14 px не используется.

### 2.4. Статусы — события BPMN

Статусы работ и сообщений обозначены событиями BPMN. Студент видит только «Не сдано», «На проверке», «На доработку», «Принята», «Попытки исчерпаны»; промежуточные статусы проверки видит только преподаватель. Значок всегда стоит рядом с цветом и подписью, поэтому статус читается и без цвета, например при дальтонизме или печати в оттенках серого.

| Статус | Значок | Цвет |
|---|---|---|
| Не сдано | Тонкий круг (начальное событие) | Графит |
| На проверке | Задача с маркером цикла, узлы ИИ мерцают | Бирюза |
| Ждёт одобрения (только у преподавателя) | Шлюз-ромб с нейросетевым узлом | Бирюза |
| Требует проверки (только у преподавателя) | Событие эскалации (стрелка вверх) | Оранжевый |
| На доработку | Событие ошибки (молния) | Красный |
| Принята | Толстый круг (конечное событие) | Зелёный |
| Попытки исчерпаны | Толстый круг с косой чертой (завершение без успеха) | Графит |
| Сообщение отправлено / есть ответ | Конверт: светлый / тёмный | Синий |
| Срок или экзамен | Событие-таймер (часы) | Оранжевый |

### 2.5. Иконки и графика

- Тонкие линейные SVG-иконки на основе элементов BPMN и аналитических схем: событие, задача, шлюз, хранилище, конверт, таймер, матрица 2×2, полосы Ганта, кривая распределения, нейросетевой узел.
- Иконки встроены в страницы, внешние наборы не подключаются.
- Фотографий и стоковых иллюстраций нет, кроме одного специального изображения `content-closed` для состояния закрытого доступа (раздел 2.5.1). Вся остальная графика — схемы.
- Нейросетевой узел (три слоя по 2–3 точки) — единственный «рисунок ИИ». Он стоит в шлюзе «Проверка», в статусе «На проверке» и в подсказках, подготовленных GPT.

### 2.5.1. Иллюстрация закрытого доступа `content-closed`

Для экрана временного закрытия учебных материалов используется отдельная локальная иллюстрация с киборгом и красным глазом. Это **символ контроля доступа**, а не знак работы ИИ: её появление не означает, что в текущем процессе участвует GPT. Цвета внутри иллюстрации не входят в палитру интерфейса и не являются статусными.

| Файл | Назначение |
|---|---|
| `static/images/content-closed.png` | Исходник 2048 × 2048 px; хранится в пакете, непосредственно на страницу не подключается |
| `static/images/content-closed-96.jpg` | Компактный значок для небольшой карточки или плашки, отображение до 96 × 96 px |
| `static/images/content-closed-640.jpg` | Основной вариант для полноценного экрана закрытого доступа, отображение до 480 × 480 px |
| `static/images/content-closed-960.jpg` | Необязательный вариант для экранов с высокой плотностью пикселей; применяется, только если страница сохраняет лимит 300 КБ |

- Изображение остаётся квадратным: не растягивается по ширине экрана, не обрезается, не перекрашивается и не анимируется.
- В обеих темах оно размещается в карточке на сплошном фоне с контуром 1 px, без теней. Текст сообщения и время окончания ограничения остаются основными; иллюстрация не заменяет их.
- Альтернативный текст: «Символ контроля доступа». Если изображение дублирует уже подписанную плашку, допускается декоративный вариант `alt=""`, чтобы экранный диктор не повторял информацию.
- Иллюстрация не используется в админке, на странице входа, в подсказках ИИ, при обычной ошибке 404 или при каждой ссылке на скрытую лекцию. Для частных скрытых материалов достаточно обычного значка таймера и подписи.

### 2.6. Сетка страницы и экраны

| Ширина экрана | Раскладка |
|---|---|
| От 1400 px | Полные меню в шапке с возможностью переноса пунктов; контент в 12 колонках, поле 32 px |
| 1200–1399 px | У студента полная процессная панель; у преподавателя разделы открываются кнопкой «Меню» |
| 992–1199 px | У студента панель сжимается до значков; у преподавателя — кнопка «Меню»; 8 колонок |
| 768–991 px | У обеих ролей разделы открываются кнопкой «Меню», ссылки раскрытого меню образуют сетку |
| До 767 px | Вертикальная дорожка-меню по кнопке и нижняя панель из 5 значков у студента; 4 колонки |
| До 380 px | Надпись логотипа скрывается, остаётся знак; меню и инструменты не выходят за экран |

Ни при одной ширине навигация не должна создавать горизонтальную прокрутку всей страницы. «Объявления» присутствуют в полном и раскрываемом меню преподавателя. Выход из аккаунта доступен в шапке и в раскрываемом меню.

## 3. Навигация с «живыми» кнопками

### 3.1. Процессная панель

Главное меню — горизонтальная BPMN-схема в шапке:

△ **Объявления** → ▭ **Лекции** → ▭ **Задания** → ◇ **Проверка** → ◎ **Мои результаты**

- Под задачей «Лекции» висят два хранилища: **Глоссарий** и **Литература**.
- Справа, через пунктирный поток с конвертом, — **Связь с преподавателем**.
- Рядом с ником и переключателем темы — пункт **«Помощь»** со значком вопроса. Внутри него две страницы: «Работа с сайтом» и «Загрузка файлов». На мобильном экране пункт находится в вертикальном меню, не увеличивая нижнюю панель из пяти значков.
- Слева — логотип, справа — ник, группа и переключатель темы.

### 3.2. Поведение кнопок

| Действие | Что видно |
|---|---|
| Наведение | Маркер-«токен» перекатывается по стрелкам к кнопке, контур кнопки становится толще |
| Нажатие | Кнопка смещается на 1 px вниз, токен остаётся на выбранном разделе |
| Активный раздел | Толстый контур, подпись раздела снизу, токен стоит на кнопке |
| Новое | Счётчик на элементе: новые объявления — на сигнале, ответы — на конверте, задания «сделать сейчас» — на задаче «Задания» |
| Ход курса | Пройденные участки стрелок закрашены: открытые лекции, сданные работы |
| Идёт проверка | Узлы нейросети в ромбе «Проверка» загораются по слоям |
| Проверка закончена | Ромб показывает значок итога: конечное событие или молния |
| Экзамен | Хранилища и задача «Лекции» заштрихованы, на них значок таймера |

### 3.3. Анимация

| Эффект | Длительность | Кривая |
|---|---|---|
| Ход токена | 350 мс | ease-in-out |
| Смена контура и цвета | 150 мс | ease-out |
| Раскрытие панели-хранилища | 250 мс | ease-out |
| Мерцание узлов ИИ | цикл 1,2 с | линейная |
| Прорисовка кривой распределения | 600 мс, один раз | ease-out |

- Ход токена, раскрытие панелей и мерцание узлов — через положение (`transform`) и прозрачность. Смена контура и цвета кнопки — короткий CSS-переход 150 мс. Прорисовка кривой — один раз, через `stroke-dashoffset` SVG. Теней, размытия и анимации размеров блоков нет, поэтому интерфейс не тормозит на слабых телефонах.
- Если в системе включено «уменьшить движение», токен переходит без движения, мерцание и прорисовка отключены.

### 3.4. Доступность

- Все кнопки доступны с клавиатуры: Tab, Enter, стрелки внутри схемы.
- Фокус — синяя рамка 2 px с отступом, видна в обеих темах.
- У каждой схемы есть текстовая подпись для экранного диктора.
- Контраст текста не ниже уровня AA (WCAG 2.1).

### 3.5. Возврат и переход наверх

- Контекстная ссылка «← назад» включается в общий шаблон, а не добавляется в каждую страницу вручную. Она есть у каждой формы и вложенной страницы и работает без JavaScript.
- Из глоссария и литературы с параметром `lecture` ведёт возврат к исходной лекции. Из ветки сообщений — к списку веток, из вложенных настроек — к настройкам, из импорта — к лекциям, из работы — к очереди, из подтверждений удаления — к данным курса.
- Для страницы без специального правила предусмотрен возврат в «Обзор» преподавателя или на «Карту курса» студента. Корневые страницы не показывают ссылку сами на себя.
- На шаге выбора группы кнопка «Изменить ник» возвращает к первому шагу без создания студента.
- Ссылки на файлы работ открывают их в новой вкладке с `rel="noopener"`; исходная страница остаётся открытой. Текст для экранного диктора сообщает о новой вкладке.
- При обязательной смене пароля не показывается возврат в закрытые настройки. Во время активного удаления данных не показывается возврат в недоступный раздел и не обещается отмена операции; доступны обновление состояния и выход.
- Возврат из формы не означает откат уже сохранённых данных, отправленных сообщений, платных запросов или запущенных фоновых задач.
- Плавающая круглая стрелка «Наверх» появляется после прокрутки более 320 px, не перекрывает нижнюю мобильную навигацию и имеет доступное название.
- Это обычная ссылка `#top`, а не только JavaScript-кнопка. В подвале дополнительно есть ссылка «Наверх», доступная без JS.
- При `prefers-reduced-motion` анимации появления и плавная прокрутка отключаются.

### 3.6. Сохранение позиции после отправки формы

- Перед отправкой любой обычной формы локальный JavaScript запоминает текущий путь и `window.scrollY` в `sessionStorage`.
- Если после ответа и перенаправления открывается тот же путь, вертикальная позиция восстанавливается сразу, без перехода наверх и без плавной прокрутки. Это относится к успешному сохранению и к повторному показу формы с ошибкой.
- Сохранённое значение используется один раз. При переходе на другой путь оно удаляется и не влияет на новый раздел.
- Содержимое полей, пароли, файлы и другие данные формы в хранилище не записываются. Ошибка или запрет `sessionStorage` не мешает отправке.
- Форма загрузки работы с фоновым прогрессом исключена, поскольку не перезагружает страницу. Формы входа, выхода, сохранения импорта и другие переходы в другой раздел автоматически не восстанавливают прежнюю позицию из-за проверки пути.
- Без JavaScript все формы продолжают отправляться; точное сохранение позиции в этом случае не требуется.
- Ручная проверка описана в `TESTING.md`; критерий приёмки — `REQUIREMENTS.md`, раздел 16.

## 5. Экраны студента

### 5.1. Вход

- Одна карточка в центре на фоне сетки. Шаг 1 — ник. Если ника нет, шаг 2 — группа (4 кнопки-задачи). Других полей нет.
- Над карточкой — короткая анимация: начальное событие → задача «Вход» → токен уходит в процесс курса.
- Сообщения об ошибках — событием ошибки с понятным текстом: «В группе уже 20 участников», «Такой ник уже занят».

### 5.2. Главная «Карта курса»

1. Шапка с процессной панелью.
2. Лента объявлений: закреплённые сверху, непрочитанные с оранжевой полосой слева, не больше трёх; ссылка «Все объявления».
3. Диаграмма Ганта «Лекции» по плановым датам: открытые лекции — сплошные полосы, анонсы — пунктир с плановой датой. Вертикальная линия «сегодня».
4. Мини-матрица заданий: четыре квадранта с числом заданий; нажатие открывает раздел «Задания».
5. Последний ответ преподавателя, если он есть.

### 5.3. Лекции

- **Список** — диаграмма Ганта по плановым датам. При наведении полоса раскрывается: части лекции, число слайдов, прогресс чтения.
- **«Слайд + текст»** — слайд слева (около 60% ширины), текст справа. Сокращения подчёркнуты пунктиром и раскрываются при наведении или касании. Под слайдом — шкала слайдов в виде полос Ганта, разделённых на части лекции; просмотренные слайды закрашены.
- **«Конспект»** — одна лента текста со слайдами-миниатюрами, слева узкое оглавление-дорожка.
- Кнопки «Сокращения лекции» и «Литература лекции» открывают панели-хранилища.
- Над текстом слайда — служебная строка лекции, если она есть (например, «Данные условные»), один раз.
- Защита от скачивания визуально незаметна: слайд — картинка, без кнопок «Скачать» и «Печать».

### 5.4. Глоссарий и литература

- Шапка в форме хранилища данных, под ней — поиск.
- Глоссарий: алфавитная лента, у каждого термина — английский оригинал, перевод и номера слайдов-ссылок.
- Литература: карточки источников с отметкой «основное / дополнительное», типом и списком лекций. Номера [n] в тексте лекции ведут к карточке.

### 5.5. Задания: матрица Эйзенхауэра

| | Срок близко (7 дней и меньше) | Срок далеко |
|---|---|---|
| **Нужно действие** (не сдано; на доработку и попытки остались) | Q1 «Сделать сейчас» | Q2 «Запланировать» |
| **Действие не нужно** | Q3 «Ждёт проверки» (на проверке) | Q4 «Завершено» (принята или попытки исчерпаны) |

- Задание без срока считается «срок далеко».
- Задание со статусом «Попытки исчерпаны» всегда в Q4, с подписью «Попытки исчерпаны» и баллами последней попытки.

- Карточка задания сама переходит между квадрантами по статусу и сроку.
- Внутри карточки — условие, срок с таймером, поле загрузки файла, попытки (не больше 4) и комментарий проверки после одобрения преподавателем.
- Загрузка файла: поле в форме задачи BPMN; во время отправки по контуру идёт полоса прогресса.

### 5.6. Результаты

- Кривая распределения баллов группы с отметкой «вы здесь». Имена и ники других студентов не показываются.
- Переключатель над кривой содержит все текущие задания в установленном преподавателем порядке и «Сумма». По заданию берутся баллы последней попытки с решением преподавателя (принята, на доработку, попытки исчерпаны). «Сумма» — сумма баллов по текущим заданиям, максимум равен их числу × 10, только у студентов, у которых решены все текущие задания.
- Кривая видна, только если в выбранном варианте не меньше 5 разных студентов группы. Иначе — надпись «Распределение появится, когда будет не меньше 5 результатов». Преподаватель может отключить кривую совсем.
- Под кривой — таблица своих баллов по всем текущим заданиям со статус-чипами.

### 5.7. Личный кабинет: личный SWOT

| S — сильные стороны | W — слабые стороны |
|---|---|
| Принятые работы, высокие баллы | Работы на доработку, низкие баллы |
| **O — возможности** | **T — угрозы** |
| Открытые, но не просмотренные лекции | Ближайшие сроки, израсходованные попытки, режим экзамена |

Квадранты заполняются автоматически по правилам:

| Квадрант | Правило |
|---|---|
| S | Задание принято с баллом 6–10. Балл 8–10 — подпись «высокий балл» |
| W | Статус «На доработку» или «Попытки исчерпаны» — при любом балле; задание принято с баллом 0–5 — подпись «принято с низким баллом» |
| O | Лекция открыта для группы, но студент просмотрел меньше половины её слайдов; задание не сдано, а до срока больше 7 дней |
| T | До срока несданного задания 7 дней и меньше; осталась 1 попытка; включён или назначен режим экзамена |

Статус важнее балла: каждое задание с решением преподавателя попадает ровно в один из квадрантов S или W. Баллы учитываются только после решения преподавателя. Каждый пункт — ссылка на нужную лекцию или задание.

### 5.8. Объявления

- Лента карточек: заголовок, текст, дата, адресат, ссылка на лекцию или задание.
- Три вида: обычное (сигнал), важное (сигнал с оранжевой рамкой, всегда закреплено), о сроке (таймер). Обычное и о сроке закрепляются отметкой преподавателя; закреплённые — первыми, со значком булавки.
- Ссылка на недоступную лекцию — серый текст без перехода с подписью «пока недоступна» или «закрыто на время экзамена».
- Непрочитанные — с оранжевой полосой слева; объявление считается прочитанным после открытия.

### 5.9. Связь с преподавателем

- Переписка нарисована двумя дорожками: «Я» и «Преподаватель». Сообщение — карточка в своей дорожке, между дорожками — пунктирный поток с конвертом.
- Окно «Вопрос преподавателю»: поле текста со счётчиком знаков (до 2000), выбор «к чему вопрос» (лекция и слайд или задание), кнопка «Отправить».
- Из лекции и задания окно открывается кнопкой-конвертом, тема и номер слайда подставляются сами.
- Статусы сообщения значками: отправлено → прочитано преподавателем → есть ответ.
- Подпись под окном: «Ответ придёт сюда, на сайт. Преподаватель получит уведомление на почту».
- Если лимит 10 сообщений в сутки исчерпан, кнопка неактивна и видно, когда она снова откроется.

### 5.10. Пустые, загрузочные и закрытые состояния

| Состояние | Что видно |
|---|---|
| Нет открытых лекций | Пустая диаграмма Ганта с линией «сегодня»: «Лекции появятся, когда их откроет преподаватель» |
| Нет объявлений | Сигнальное событие в тонком контуре: «Пока объявлений нет» |
| Нет сообщений | Две пустые дорожки и кнопка «Задать вопрос» |
| Загрузка страницы | Серые полосы Ганта на месте контента |
| Режим экзамена | Штриховка на лекциях, глоссарии и литературе, таймер и время окончания |
| Сервер недоступен | Событие ошибки: «Сайт временно недоступен, попробуйте позже» |

На полноценной странице закрытого экзаменом раздела показывается `content-closed-640.jpg`: на широком экране — слева от сообщения, на мобильном — над сообщением, не больше 320 px по стороне. Заголовок: «Доступ к учебным материалам закрыт на время экзамена». Ниже — время окончания, если оно задано, и доступные действия «Перейти к заданиям», «Написать преподавателю», «Открыть помощь». В компактной плашке вместо большого изображения используется `content-closed-96.jpg`. Если страница с материалами закрыта по другой причине, текст указывает фактическую причину, а не экзамен.

### 5.11. Помощь и загрузка файлов

- Пункт «Помощь» открывает две серверные страницы: «Работа с сайтом» и «Загрузка файлов». В начале длинной страницы — оглавление с якорными ссылками.
- Студент видит только студенческие инструкции: возможности сайта и загрузку домашних работ. Переключателя ролей и преподавательских ссылок у него нет.
- Преподаватель видит переключатель «Студенту / Преподавателю» на обеих страницах; по умолчанию открыт преподавательский вариант.
- Инструкции оформлены существующими карточками, нумерованными шагами и таблицами ограничений. Таблицы на узком экране перестраиваются в карточки либо получают доступную горизонтальную прокрутку внутри компонента, без прокрутки всей страницы.
- Ссылка «Как загрузить работу» в карточке задания открывает студенческую инструкцию по загрузке. Ссылка «Инструкция по загрузке лекции» в форме импорта открывает преподавательский вариант.
- Обе страницы доступны во время экзамена, читаются без JavaScript и используют только локальные ресурсы. Содержание — `06-HELP.md`.

## 6. Экраны преподавателя (админка)

- Тот же визуальный язык, но плотнее: меньше отступов, без анимации токена.
- **Расписание лекций** — диаграмма Ганта по плановым датам: полосу можно перетащить, чтобы изменить плановую дату. Открытие лекции от даты не зависит: у полосы — переключатель «Скрыта / Открыта», «Анонс» и выбор групп. Кнопка «Режим студента» у полосы показывает лекцию так, как её увидят студенты; для скрытых лекций этот просмотр доступен только преподавателю.
- **Загрузка лекции** — процесс из трёх шагов на одной схеме: файлы → проверки (совпадение слайдов, заметки, сокращения, литература) → сохранение. Каждый шаг закрашивается по готовности, ошибки показаны молнией.
- **Экраны подтверждения** глоссария, сокращений и литературы — три колонки «новые / уже есть / конфликты».
- **Результаты** — таблица «группа — студент — работа — статус» и распределение баллов по группам.
- **Совпадения** — в очереди проверки показывается максимальный процент, а в экране работы — таблица процентов по последним проверенным работам других студентов. Рядом есть пояснение, что оценка ИИ не является самостоятельным доказательством списывания. Студентам эти данные не показываются.
- **Помощь** — те же страницы «Работа с сайтом» и «Загрузка файлов», но с переключателем «Студенту / Преподавателю». Преподавателю доступны обе версии, включая инструкцию по импорту лекций.
- **Агент проверки** — кривая уверенности ответов ИИ с порогом 0,7: при сдвиге порога видно, сколько работ уйдёт в «Требует проверки».
- **Сообщения** — слева список веток по никам (непрочитанные сверху), справа — ветка в виде двух дорожек и поле ответа.
- **Объявления** — пункт полного и раскрываемого меню. Редактор содержит заголовок, текст, выбор групп, вид, закрепление, даты публикации и снятия; необязательных ссылок на лекции и задания нет.
- **Режим экзамена** — один крупный переключатель с таймером и выбором групп.
- **Монитор ProxyAPI** (Настройки → ProxyAPI) — баланс в виде шкалы-«бака» с двумя отметками порогов «мало» и «критично», под ней прогноз «хватит примерно на N проверок, до даты», расход за день, неделю и месяц, линия баланса за 30 дней, список последних ошибок. Уровни цветом и значком события BPMN: норма — тонкий круг, графит; мало — событие эскалации, оранжевый; критично — событие эскалации, красный; нет средств — событие ошибки, красный; баланс неизвестен — пунктирный круг, серый; ключ отклонён или нет доступа к модели — событие ошибки, красный, с текстом «Проверьте ключ ProxyAPI». Та же плашка уровня стоит на главной странице админки.

## 7. Логотип hwstud

Ромб-шлюз BPMN, внутри — три соединённых узла нейросети, рядом надпись «hwstud» шрифтом Plex Mono. Смысл: решение по работе принимается на стыке ИИ и человека. Варианты: полный (знак и надпись), знак отдельно для иконки сайта, одноцветный.

## 8. Логотип AI&HI: ограниченное использование

Логотип AI&HI взят с сайта-портфолио [ai-and-hi.pplx.app](https://ai-and-hi.pplx.app). Это подпись автора курса, а не знак сайта: сайт курса узнаётся по своему логотипу hwstud, AI&HI стоит только в нескольких местах.

### 8.1. Состав логотипа

- Знак: две фигуры, синяя (#1124E2) и оранжевая (#FF9D01), вместе образуют букву «H».
- Надпись «AI&HI» с переходом цвета от синего к оранжевому и строка «AI SOLUTIONS».
- Два готовых варианта с прозрачным фоном: для светлого фона (тёмная строка «AI SOLUTIONS») и для тёмного (светлая строка). Файлы logo-on-light.webp и logo-on-dark.webp, 360 × 120 px, лежат в static/brand/ этого пакета.
- Смысл логотипа совпадает с принципом курса «человек в контуре»: AI — искусственный интеллект (Artificial Intelligence), HI — человеческий интеллект (Human Intelligence).

### 8.2. Где используется

| Место | Вариант | Размер |
|---|---|---|
| Подвал страниц студента, кроме `/about`: «Разработка курса и сайта — AI&HI», ссылка на портфолио. В админке подвала с логотипом нет | Полный, по теме страницы | Десктоп: 144 × 48 px; мобильный: 192 × 64 px |
| Страницы входа, под карточкой входа | Полный, по теме страницы, в общем подвале, без ссылки на портфолио | Десктоп: 144 × 48 px; мобильный: 192 × 64 px |
| Страница «О курсе и авторе» (`/about`, содержание — `01-FUNCTIONS.md`, раздел 13), только карточка автора, без повтора в подвале | Полный, по теме страницы | Десктоп: 180 × 60 px; мобильный: 240 × 80 px |
| Колонтитул выгрузок PDF и DOCX (глоссарий, литература) | Полный, для светлого фона | Высота 12 мм, пропорции 3:1 |

### 8.3. Где не используется

- В шапке, процессной панели и меню: там только логотип hwstud.
- В иконке сайта (favicon): там знак hwstud.
- На слайдах и в тексте лекций, в заданиях, в объявлениях и в переписке.
- Рядом со статусами, счётчиками и подсказками ИИ, чтобы его цвета не путали с цветами статусов.
- В анимации: логотип AI&HI всегда неподвижен.
- В админке, включая её подвал: преподавателю подпись автора не нужна.

### 8.4. Правила

- Логотип не перекрашивается, не растягивается, не поворачивается и не обрезается. Знак отдельно от надписи не используется.
- Синий и оранжевый цвета AI&HI остаются только внутри логотипа и не входят в палитру сайта. Сигнальный оранжевый сайта (#E8833A) — другой цвет, с другим значением.
- Свободное поле вокруг логотипа — не меньше высоты головы фигуры знака.
- Логотип стоит на сплошном фоне подвала или карточки, не на миллиметровой сетке.
- На светлой теме — вариант для светлого фона, на тёмной «Синьке» — вариант для тёмного.
- Высота полного логотипа не меньше 32 px на экране, иначе строка «AI SOLUTIONS» не читается.
- Логотип hwstud и логотип AI&HI не стоят рядом: между ними всегда другой контент или вся ширина страницы.

## 9. Тон текстов интерфейса

- Научно-технический стиль, короткие фразы, без восклицаний.
- Термины курса — с английским оригиналом и переводом при первом упоминании на экране: «шлюз (gateway)», «хранилище данных (data store)».
- Кнопки называют действие: «Сдать работу», «Задать вопрос», «Открыть лекцию».
- Ошибки объясняют, что делать: «Файл больше 10 МБ. Сожмите PDF или загрузите фото страниц».

## 10. Техническая сторона дизайна

- Страницы собираются на сервере (FastAPI и шаблоны Jinja), без тяжёлых фреймворков.
- Интерактивность — небольшой собственный JavaScript и SVG, без внешних библиотек и CDN.
- Темы реализуются через CSS-переменные, переключение без перезагрузки страницы.
- Шрифты, иконки и файлы логотипов hwstud и AI&HI хранятся на сервере. Внешних сервисов два: ProxyAPI (модели GPT) и SMTP-сервер почтового ящика преподавателя.
- После изменения общих CSS или JavaScript в их URL обновляется параметр версии, чтобы браузер получил новый файл вместо недельного кеша.
- Размер страницы без слайдов — до 300 КБ, чтобы сайт быстро открывался с телефона.
